---
name: eng-plan
description: Design a consequential feature or refactor with acceptance criteria, decisions, dependencies, verification, and rollout before implementation.
---

Read relevant instructions and design authority, then map affected behavior and ownership. State acceptance criteria and unresolved decisions. Distinguish user decisions, assistant-selected implementation choices, verified observations, and proposals.

Compare alternatives where correctness, compatibility, cost, or operational risk differ. Cover affected interfaces, error behavior, migration order, and rollback. Ask for product decisions only when they cannot be inferred; continue independent discovery.

Size the plan to the task with dependencies and observable completion. Use existing design/decision stores, link delivery records to them, and separate planned checks from executed evidence. Mark superseded decisions and update current indexes.

For multiple repositories identify producer/consumer revisions and integration ownership. Worker briefs need bounded deliverables, allowed files/actions, and stopping conditions. Planning does not authorize publication or active agent-policy changes.
